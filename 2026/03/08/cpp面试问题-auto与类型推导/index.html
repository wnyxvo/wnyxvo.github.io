第一章 auto与类型推导

问题1：解释auto类型推导！

auto类型推导通常与模板类型推导相同，但auto类型推导假定用大括号括起来的初始化器代表std::initializer_list，而模板类型推导并不持有这样的前提。

This type is used to access the values in a C++ initialization list, which is a list of elements of type const T.

C++11 引入的轻量级模板类（定义于 <initializer_list>头文件）

本质是对底层数组的引用，不拥有数据所有权，拷贝时仅复制指针而非数据。元素为 const类型，不可修改、所有元素类型必须相同、初始化后元素数量固定，运行时无法增删

用途：

  • 容器初始化
  • 自定义类的初始化
  • 函数参数传递：支持可变数量的同类型参数
  • 操作符重载

const int* const cicp包含两个const修饰符：

  • 左侧 const：底层常量性（指向的数据不可修改 → const int*）。
  • 右侧 const：顶层常量性（指针本身不可修改 → * const）。

auto会忽略顶层 const（即指针本身的常量性），但保留底层 const（指向的数据的常量性）；auto默认忽略引用

若需完全保留双重常量性，使用 decltype显式声明：

可以看出，如果使用大括号初始化器，auto会强制创建一个std::initializer_list类型的变量。如果它无法推导出T的类型，代码就会被拒绝。

我们也看到，auto可以为指针推导出正确的类型，但为了得到引用，我们必须写成auto&。为了保持一致性，如果我们期望得到一个指针，也可以写成auto*。

在函数返回类型或lambda参数中使用auto意味着进行模板类型推导，而非auto类型推导。
