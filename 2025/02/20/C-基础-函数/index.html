函数基础

局部对象

在C++中，名字有作用域，对象有生命周期。

  • 名字的作用域是程序文本的一部分，名字在其中可见。
  • 对象的生命周期是程序执行过程中该对象存在的一段时间。

局部变量（local variable）：形参和函数体内部定义的变量统称为局部变量。它对函数而言是局部的，对函数外部而言是不可见的。局部变量的生命周期取决于定义方式。

自动对象：只存在于块执行期间的对象。当块的执行结束后，它的值就变成未定义的了。函数的形参就是一种自动对象，一旦函数终止，形参就会被销毁。

局部静态对象： static类型的局部变量，生命周期贯穿函数调用前后，在函数外仍然是不可见的。局部静态对象只在执行路径第一次经过对象定义语句时初始化，可以用来统计一个函数被调用的次数。

参数传递

两种传参方式：值传递（passed by value）、引用传递（passed by reference）。建议使用引用传递代替指针形参。

使用引用避免拷贝。如果函数无须改变形参的值，最好将其声明为常量引用。被常量引用（const &）引用的参数在引用的作用域内不能被修改，但如果它本身是一个可变的变量，它仍然可以在其他作用域被修改。

当函数返回值较大或想要多个返回值时，可以使用引用形参返回，这样可以避免拷贝。

不能将普通引用绑定到 const 对象：所以要尽量使用常量引用。

数组形参

数组不允许拷贝和赋值，所以为函数传递一个数组时，实际上传递的是指向数组首元素的指针。

数组是以指针的形式传递给函数，函数一开始并不知道数组的尺寸。管理指针形参有三种常用技术：

  • 使用标记指定数组长度。要求数组本身包含一个介绍标记，如 C 风格字符串。
  • 使用标准库规范。传递指向数组首元素和尾后元素的指针。
  • 显示传递一个表示数组大小的形参。

可变形参

  • initializer_list
  • 省略形参符： ...，便于C++访问某些C代码，这些C代码使用了 varargs的C标准功能。

返回类型和 return 语句

  • 值的返回：返回的值用于初始化调用点的一个临时量，该临时量就是函数调用的结果。
  • 引用返回左值：函数的返回类型决定函数调用是否是左值。调用一个返回引用的函数得到左值；其他返回类型得到右值。
  • 列表初始化返回值：函数可以返回花括号包围的值的列表。（C++11）

返回数组指针

  • 声明一个返回数组指针的函数，函数的形参列表跟在函数名称后面且形参列表应该先于数组的维度

  • 尾置返回类型： 在形参列表后面以一个->开始：auto func(int i) -> int(*)[10]（C++11）

  • 使用 decltype： decltype(odd) *arrPtr(int i) {...}。这个要知道函数返回哪个数组。

内联函数

inline只是建议编译器优化，加或不加编译器都有可能优化或不优化。

内联函数与宏的区别：宏不安全

  • 宏是预处理指令，由预处理器完成文本替换。
  • 类型安全： 内联函数具有类型检查，宏则没有。内联函数会在编译时进行类型检查，而宏只是简单的文本替换，不关心类型。

内联函数的适用场景：短小的、频繁调用的函数

函数重载

重载：如果同一作用域内几个函数名字相同但形参列表不同，我们称之为重载（overload）函数。注意返回值不计入，当两个函数的名称和参数列表完全相同而返回值不同时，编译器会报错认为这是重复定义。

main函数不能重载。

重载和const形参：

  • 一个有顶层const的形参和没有它的函数无法区分。 Record lookup(Phone* const)和 Record lookup(Phone*)无法区分。

  • 相反，是否有某个底层const形参可以区分。 Record lookup(Account*)和 Record lookup(const Account*)可以区分。

  • 顶层const：表示指针本身是个常量；底层const：表示指针所指的对象是一个常量

  • 重载和作用域：若在内层作用域中声明名字，它将隐藏外层作用域中声明的同名实体，在不同的作用域中无法重载函数名。
