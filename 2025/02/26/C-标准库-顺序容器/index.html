顺序容器概述

概述

顺序容器（sequential container）：为程序员提供了控制元素存储和访问顺序的能力。这种顺序不依赖于元素的值，而是与元素加入容器时的位置相对应。它们以线性顺序存储和管理元素。

容器 底层结构 访问方式 适用场景
vector 动态数组 随机访问 O(1) 需要高效随机访问，元素增删较少的情况
deque 双端队列 随机访问 O(1)，前后插入快 需要在头部和尾部都能快速插入和删除
list 双向链表 双向迭代，访问 O(n) 需要高效插入、删除（O(1)），但不要求随机访问
forward_list 单向链表 单向迭代，访问 O(n) 仅需要前向遍历的链表，适合内存受限环境
array 定长数组 随机访问 O(1) 知道固定大小时，使用比 vector 更快
string 动态数组 随机访问 O(1) 用于字符串处理
  • 除了array固定大小外，其他容器都提供高效、灵活的内存管理。
  • 通常使用vector是最好的选择，除非你有很好的理由选择其他容器。
  • vector 适合随机访问多、插入删除少的场景。
  • deque 适合需要高效的头部和尾部操作的场景。
  • list 适合频繁插入和删除但不需要随机访问的情况。
  • forward_list 适合只需单向遍历并优化内存的场景。
  • array 适合大小固定、性能优化的情况。

容器库概述

在本节介绍对所有容器都适用的操作。

类型别名

类型别名 说明 示例（std::vector<int>）
iterator 迭代器类型（指向元素） vector<int>::iterator → std::vector<int>::iterator
const_reference 元素的常量引用类型 vector<int>::const_reference → const int&
size_type 表示容器大小的无符号整数类型 vector<int>::size_type → std::size_t
value_type 存储的元素类型 vector<int>::value_type → int
pointer 指向元素的指针类型 vector<int>::pointer → int*
difference_type 迭代器之间的距离（用于指针差值计算） vector<int>::difference_type → std::ptrdiff_t
iterator 迭代器类型（指向元素） vector<int>::iterator → std::vector<int>::iterator

迭代器

迭代器（Iterator） 是 C++ STL（标准模板库）中的一种对象，用于遍历容器（如 vector、list、map 等）。迭代器类似于指针，可以用于访问容器中的元素，并支持递增、递减等操作。

迭代器范围（Iterator Range） 是表示一段容器元素范围的方式，通常由起始迭代器（begin）和结束迭代器（end）组成。迭代器范围的约定是左闭右开（[begin, end)），即包含 begin 指向的元素，但不包含 end 指向的元素。

  • begin 指向范围的起始位置，end 指向超出范围的下一个位置。
  • end 不能被解引用（*end 是未定义行为）。

构造函数

名称 说明
默认 创建一个空容器
指定大小 创建一个指定大小的容器，默认初始化值
指定大小并初始化 创建一个指定大小并初始化所有元素的容器
范围构造 通过迭代器范围 [first, last) 构造新容器
拷贝构造 用另一个同类型容器构造新容器（深拷贝）
移动构造 通过 std::move() 接管另一个容器的数据，避免拷贝，提高性能
初始化列表 直接使用 {} 进行初始化
  • 只有顺序容器的构造函数才接受大小参数，关联容器并不支持。
  • array具有固定大小。当定义array容器时要指定大小和元素类型，大小也是类型的一部分。array支持拷贝或对象赋值操作，而内置数组不支持。
  • 和其他容器不同，默认构造的array是非空的。
  • 直接复制拷贝：将一个容器复制给另一个容器时，类型必须匹配：容器类型和元素类型都必须相同。
  • 使用迭代器复制：不要求容器类型相同，容器内的元素类型也可以不同。

赋值与swap

赋值运算符 =用一个容器的内容替换另一个容器的内容。左边容器的迭代器、指针和引用失效

array不支持{}赋值和assign，因为array要求赋值的两边的类型一致，这两种方式不能保证一致。

使用assign（仅顺序容器），时间复杂度：O(n)

swap() 交换，交换两个容器的内容，不涉及数据拷贝，只是交换指针或内部数据结构，性能极高（O(1)）。swap() 不会重新分配内存。

元素不移动意味着，除string外，swap() 交换后指向容器的迭代器、指针和引用不会失效。它们仍指向交换前指向的元素。swap() 成员函数、std::swap()（全局函数）；使用非成员版本的swap是一个好习惯。

特例，swap() 两个string会真正交换元素，因此耗时也就和元素个数成正比。

容器大小

除了forward_list外，每个容器类型都有三个与大小相关的操作：

  • size()返回容器中元素的数目。
  • empty() 返回 true 表示容器为空，false 表示容器有元素。避免 if (v.size() == 0)，推荐使用 if (v.empty())。
  • max_size()返回容器理论上可以存储的最大元素数量，具体数值依赖于系统和编译器。

对于vector 和 string还有个capacity() 返回当前分配的存储空间可容纳的元素个数，不一定等于 size()。

关系运算符

关系运算符两边的对象必须是相同类型的容器，且必须保存相同类型的元素。

==和!=判断两个容器的元素是否完全相等（大小相同 & 元素值相同）。<、>、<=、>=）都基于字典序比较。

顺序容器操作

添加

方法 适用容器 位置 适用情况
push_back() vector、deque、list、string 末尾 追加元素
push_front() deque、forward_list、list 头部 插入头部
insert() 所有顺序容器 指定位置 插入单个/多个元素
emplace_back() vector、list、deque 末尾 直接构造元素
emplace_front() list、deque 头部 直接构造元素
resize() vector、deque、list - 调整大小
splice() list 指定位置 O(1) 复杂度移动元素

  • 因为这些操作会改变大小，因此不适用于array。

  • insert()接受迭代器来指向要插入的位置，这个迭代器可以指向任何地方，包括首部和尾部之后的下一个位置，但可能很耗时。

  • insert()在C++11标准后，返回指向第一个新加入元素的迭代器。

  • emplace(args...) 直接在容器内存中构造对象，避免不必要的拷贝。更适用于对象类型（如 std::string、自定义类）。传递给emplace的参数必须和元素类型的构造函数相匹配。

访问

操作 解释
back() 返回c中尾元素的引用。若c为空，函数行为未定义
front() 返回c中头元素的引用。若c为空，函数行为未定义
c[n] 返回c中下标是n的元素的引用，n时候一个无符号证书。若n>=c.size()，则函数行为未定义
c.at(n) 返回下标为n的元素引用。如果下标越界，则抛出out_of_range异常

  • 上边的访问成员函数返回都是引用。

  • at和下标操作只适用于string、vector、deque、array。

  • back不适用于forward_list。

  • 通过迭代器访问第一个元素，需解引用 (*c.begin())。

删除

操作 解释
pop_back() 删除c中尾元素，若c为空，则函数行为未定义。函数返回void
pop_front() 删除c中首元素，若c为空，则函数行为未定义。函数返回void
erase(p) 删除迭代器p指向的元素，返回一个指向被删除元素之后的元素的迭代器，若p本身是尾后迭代器，则函数行为未定义
erase(b, e) 删除迭代器b和e范围内的元素，返回指向最后一个被删元素之后元素的迭代器，若e本身就是尾后迭代器，则返回尾后迭代器
clear() 删除c中所有元素，返回void
  • vector和string不支持pop_front
  • 这些操作会改变容器大小，不适用于array。

特殊的forwad_list操作

单链表在添加或删除元素时需要修改前置节点的内容，而在单链表中无法获取前置链表。所以在单链表中的操作都是改变给定元素之后的元素。如A->B->C，现在要删除B，参数就是指向A的迭代器。

forward_list还定义了before_begin，即首前（off-the-begining）迭代器，允许在首元素之前添加或删除元素。

操作 解释
lst.before_begin() 返回指向链表首元素之前不存在的元素的迭代器，此迭代器不能解引用。
lst.cbefore_begin() 同上，但是返回的是常量迭代器。
lst.insert_after(p, t) 在迭代器p之后插入元素。t是一个对象
lst.insert_after(p, n, t) 在迭代器p之后插入元素。t是一个对象，n是数量。若n是0则函数行为未定义
lst.insert_after(p, b, e) 在迭代器p之后插入元素。由迭代器b和e指定范围。
lst.insert_after(p, il) 在迭代器p之后插入元素。由il指定初始化列表。
emplace_after(p, args) 使用args在p之后的位置，创建一个元素，返回一个指向这个新元素的迭代器。若p为尾后迭代器，则函数行为未定义。
lst.erase_after(p) 删除p指向位置之后的元素，返回一个指向被删元素之后的元素的迭代器，若p指向lst的尾元素或者是一个尾后迭代器，则函数行为未定义。
lst.erase_after(b, e) 类似上面，删除对象换成从b到e指定的范围。

改变容器大小

  • c.resize(n) ：调整c的大小为n个元素，若n<c.size()，则多出的元素被丢弃。若必须添加新元素，对新元素进行值初始化。

  • c.resize(n, t)：调整c的大小为n个元素，任何新添加的元素都初始化为值t

缩小容器，则指向被删除容器的迭代器、指针、引用都会失效。

容器操作可能使迭代器失效

在向容器添加元素后：

  • 如果容器是vector或string，且存储空间被重新分配，则指向容器的迭代器、指针、引用都会失效。
  • 对于deque，插入到除首尾位置之外的任何位置都会导致指向容器的迭代器、指针、引用失效。如果在首尾位置添加元素，迭代器会失效，但指向存在元素的引用和指针不会失效。
  • 对于list和forward_list，指向容器的迭代器、指针和引用依然有效。

在从一个容器中删除元素后：

  • 对于list和forward_list，指向容器其他位置的迭代器、引用和指针仍然有效。
  • 对于deque，如果在首尾之外的任何位置删除元素，那么指向被删除元素外其他元素的迭代器、指针、引用都会失效；如果是删除deque的尾元素，则尾后迭代器会失效，但其他不受影响；如果删除的是deque的头元素，这些也不会受影响。
  • 对于vector和string，指向被删元素之前的迭代器、引用、指针仍然有效。
  • 注意：当我们删除元素时，尾后迭代器总是会失效。
  • 注意：使用失效的迭代器、指针、引用是严重的运行时错误！
  • 建议：将要求迭代器必须保持有效的程序片段最小化。
  • 建议：不要保存end返回的迭代器。

vector 对象是如何增长的

vector和string在内存中是连续保存的，如果原先分配的内存位置已经使用完，则需要重新分配新空间，将已有元素从就位置移动到新空间中，然后添加新元素。为了减少这种代价，给vector和string实际分配的空间会比需求大。

管理容器的成员函数：

  • capacity()：在不重新分配空间的情况下，可以保存多少个元素。capacity()>=size()
  • reserve(n)：分配至少能容纳 n 个元素的内存空间。改变的是预先分配多大的内存空间。只有当 n 大于当前容量时，才会扩容。当 n 小于或等于当前容量，reserve什么也不做。调用reserve永远不会减少容量。
  • shrink_to_fit()：将capacity()减少到和size()相同大小。不保证一定退回内存空间。
  • shrink_to_fit只适用于vector、string和deque
  • capacity和reserve只适用于vector和string。

额外的 string 操作

容器适配器

容器适配器（Container Adapters）是C++ 标准库（STL）提供的一种封装，它们基于基本的顺序容器（如 vector、deque 和 list），但限制了一些功能，并提供了特定的操作方式，以适应特定的数据结构需求，例如 栈（stack）、队列（queue）、优先队列（priority_queue）。

适配器的通用操作：

操作 解释
size_type 一种类型，须以保存当前类型的最大对象的大小
value_type 元素类型
container_type 实现适配器的底层容器类型
A a; 创建一个名为a的空适配器
A a(c) 创建一个名为a的适配器，带有容器c的一个拷贝
关系运算符 每个适配器都支持所有关系运算符：==、!=、<、 <=、>、>=这些运算符返回底层容器的比较结果
a.empty() 若a包含任何元素，返回false;否则返回true
a.size() 返回a中的元素数目
swap(a, b) 交换a和b的内容，a和b必须有相同类型，包括底层容器类型也必须相同
a.swap(b) 同上

std::stack<T>（栈）

  • 后进先出（LIFO） 结构；只能从栈顶插入和删除元素
  • 默认底层容器：std::deque<T>；也可以使用 std::vector<T> 或 std::list<T> 作为底层容器

stack 的构造：

操作 解释
s.pop() 删除栈顶元素，不返回。
s.push(item) 创建一个新元素，压入栈顶，该元素通过拷贝或移动item而来
s.emplace(args) 同上，但元素由args来构造。
s.top() 返回栈顶元素的引用，不删除。

std::queue<T>（队列）

  • 先进先出（FIFO） 结构；只能从队尾插入，从队头删除

  • 默认底层容器：std::deque<T>

  • 支持pop()、push()、emplace()、front()、back()

std::priority_queue<T>（优先队列）

  • 默认实现为最大堆（最大值优先）；也可以通过 自定义比较器 实现最小堆
  • 默认底层容器：std::vector<T>，并使用 std::make_heap 维护堆结构
  • 支持pop()、push()、emplace()、front()、top()
