C++标准库-泛型算法

发表于 2025-03-03 更新于 2025-03-27 分类于 C++
本文字数： 2.1k 阅读时长 ≈ 2 分钟

概述

泛型算法 是指可以与 不同类型的数据 结合使用的通用算法，主要依赖 模板（Template） 机制实现。C++ 的标准库（STL）提供了一系列 基于迭代器的泛型算法，如 std::sort、std::find、std::for_each 等。C++ STL 的泛型算法主要在 <algorithm> 和 <numeric> 头文件中定义。

  • 泛型算法本身不执行容器操作，只是单独依赖迭代器和迭代器操作实现。
  • 除了少数例外，泛型算法都是对一个范围内（由迭代器指定）的元素进行操作。
  • 泛型算法永远不会改变底层容器的大小。算法可能改变容器中保存的元素的值，也可能在容器内移动元素，但不能直接添加或者删除元素。

初识泛型算法

只读类算法

一类算法只会读取输入范围内的元素，而不改变元素。如find()和accmulate()。

  • 第三个参数作为求和的初值，同时也指定了函数中使用哪个加法操作符和返回值的类型。同时注意一些类型可能没有默认的加法操作，如 const char*。
  • 对于只读取不改变元素的算法，通常使用cbegin()和cend()。
  • 默认第二个序列至少和第一个序列一样长
  • 两个序列中的元素类型不必一样

写容器元素的算法

泛型算法不会执行容器操作，它们自身不可能改变容器的大小。

泛型算法不会检查写操作是否超出范围。如fill_n(vec.begin(), 10, 0)，但这是个空的容器。

fill

  • fill： fill(vec.begin(), vec.end(), 0);
  • fill_n： fill_n(vec.begin(), 10, 0);

back_inserter

插入迭代器std::back_inserter 可以确保算法在插入数据时有足够的空间，这是因为它利用了容器的 push_back 方法。插入迭代器是函数，但它们的返回值是迭代器对象，可以像普通迭代器一样使用。

std::back_inserter() 的实现：

*it = value 实际上是在调用 push_back(value);。所以仅适用于支持 push_back 的容器（vector、deque 等），不适用于 std::set、std::map。

常常使用back_inserter 来创建一个迭代器，作为算法的目的地址使用。

copy

用于将一个范围内的元素复制到另一个范围。

返回值：返回目标范围的下一个迭代器。

std::copy + back_inserter（自动扩展目标容器）:

如果目标范围与源范围部分重叠，会导致未定义行为（UB）。
